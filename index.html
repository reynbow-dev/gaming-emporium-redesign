        Redesign Notes

        Thousands of hand-picked projects, updated almost every day. The site struggles to makeobvious to someone landing here for the first time, what the purpose is.

        1. The page opens with one obvious sentence: a hand-curated index of fan decomps, ports, hacks and remakes, linking to each project’s own page. Nobody has to click around to work it out.
        2. The floating cluster of pills needed to be replaced. Browsing links, search and a single “Suggest a project” button sit in one line along the top.
        3. Fewer buttons with nothing hidden in pop-ups. Surprise Me, Hidden Gems, Top 50 Rising and Most Popular live together in one section with tabs. Site Stats became numbers shown right on the page. RSS, Follow, Install and the theme switch moved to the footer.
        4. Favourites show up when they matter. Heart a project and a “Saved” link appears in the header. Until then, it stays out of the way.
        5. The carousel is replaced by a list of all 17 categories, sorted into four groups, each with a count and a short description of what you’ll find.
        6. Each project explains itself. A small yellow strip shows where a game started and where it runs now, like N64 → PC or GameCube → Android. Titles have an external-link icon, so it’s clear the link takes you to the project’s own site, whether that’s GitHub, itch.io or elsewhere.
        7. Comments have a clear purpose. The section says it’s for talking about the site itself, and shows the newest comments first so it stays current.
        8. Suggesting a project takes one step. The form sits right on the page instead of in a pop-up.

        About the content in this mockup

        • The order of the lists under the four tabs is just an example.
        • The October comments are made-up examples; the two older ones are real.
        • The group names and category descriptions are suggestions.
